🔍 Overview
This project is all about getting comfortable with Webpack, a robust tool used to bundle JavaScript modules. You'll walk through the steps to configure Webpack from scratch, handle files with loaders, enhance the build with plugins, and spin up a dev server to streamline your workflow.

📚 Resources
To help guide your setup, check out the following:

Official Webpack Docs

Webpack Beginner's Tutorial (YouTube / Blog)

Intro to package.json and npm

🎯 Learning Goals
By the end of this project, you should be able to confidently explain:

🔧 How to configure Webpack in a project

🏗 What entry, output, and loaders are, and how they work together

🧩 How to use plugins to add extra functionality

✂️ Code splitting and why it's useful

🌐 How to launch and configure a development server

✅ Project Requirements
All code will be tested on Ubuntu 20.04 LTS using Node.js 20.x.x and npm 9.x.x

You may use any of these editors: vi, vim, emacs, or Visual Studio Code

Every file should end with a newline character

A README.md file is required at the root of your project directory
