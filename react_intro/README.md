## 🎯 Learning Objectives

By the end of this project, you should be able to confidently explain and demonstrate the following concepts:

- ✅ How to create a basic JavaScript application with **React**
- 🚀 How to use the build tool **Vite** to start developing quickly with React
- 🧠 What **JSX** is and how it works
- 🎨 How to add **inline styles** in React
- 📋 How to implement **simple forms** in React
- 🧪 How to implement **unit tests** using React Testing Library
- 🛠️ How to use the **React Developer Tools** to debug your code
- 🌐 How to **deploy a React application to GitHub Pages**

## ⚙️ Requirements

- All code must run on **Ubuntu 20.04 LTS**
- Must use **Node.js 20.x.x or greater** and **npm 10.x.x**
- Use any of the following editors: `vi`, `vim`, `emacs`, or **Visual Studio Code**
- All source files must **end with a new line**
- A `README.md` is **required** at the root of the project and each task’s folder
- Install **Jest globally**:

  ```bash
  npm install -g jest
  ```
